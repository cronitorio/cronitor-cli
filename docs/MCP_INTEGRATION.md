# Dashboard MCP integration

The dashboard MCP server now lives in the
[Crontab Guru Dashboard repository](https://github.com/cronitorio/crontab-dashboard).
Install its bundled release, then run `crontab-dashboard --mcp-instance default`.
`cronitor dash --mcp-instance default` remains a compatibility launcher.

See the [standalone MCP guide](https://github.com/cronitorio/crontab-dashboard/blob/main/docs/MCP_INTEGRATION.md)
for instance configuration and available tools.
