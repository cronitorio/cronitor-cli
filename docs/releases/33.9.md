## What's new

- `cronitor auth login` and `cronitor signup` now wait 30 minutes by default for you to open the authorization link, up from 5 minutes. The CLI prints the local deadline on the line after the URL. Once you open the link, finish signing in within about 5 minutes. Pass `--timeout` to wait longer or shorter.
- Fixed `cronitor site query`, which returned a 400 error for every query. The CLI now sends `kind`, `aggregate`, and `group_by` as the Sites API expects. `--type` and `--metric` still work, and `--kind` and `--aggregate` are accepted as aliases.
- `cronitor site query --search ""` now sends an empty search, and `--format table` shows error groups as `key` plus the aggregates you requested. The `--help` examples use valid field names.
