## What's new

- Fixed `cronitor dash`, `cronitor auth login`, `cronitor signup`, and OAuth connect on Windows opening a truncated authorization URL in the browser, which showed an "Authorization Error / invalid parameters" page. The CLI now opens URLs with `rundll32 url.dll,FileProtocolHandler` instead of `cmd /c start`, so query strings containing `&` stay intact. FreeBSD, OpenBSD, and NetBSD now open the browser with `xdg-open` ([#75](https://github.com/cronitorio/cronitor-cli/pull/75)).
- Linux CI tests now pass their environment variables through `sudo` on `ubuntu-26.04` runners ([#76](https://github.com/cronitorio/cronitor-cli/pull/76)).
