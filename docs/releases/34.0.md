## What's new

- Added `cronitor team list`, `cronitor team invite`, `cronitor team role`, and `cronitor team remove`. A member's id is their email address.
- Added `cronitor apikey` to list, get, create, update, and delete API keys. The table masks each key, and `--format json` prints it in full.
- `cronitor auth login --admin` creates an account-access key. `cronitor team` and `cronitor apikey` then act with your current role.
- Removing a team member deletes only keys created with `cronitor auth login --admin`. Keys from a plain `cronitor auth login` belong to the organization and keep working. Demoting someone does not reduce what their existing keys can already do, so delete their keys and have them log in again.
- The common flag table now says `--format` is `json` or `table` (`yaml` is only for `monitor`) and that `-f`/`--file` applies to `monitor create`/`update` and `integration create`.
- `cronitor team` and `cronitor apikey` need the matching server release (cronitor #467).
