## What's new

- Release binaries are now built with Go 1.26.10, the latest 1.26 patch, up from 1.26.2. On 1.26.2, govulncheck reported 23 Go standard library vulnerabilities reachable from the CLI (in crypto/x509, net/http, crypto/tls, net/url, encoding/asn1, and mime/multipart). On 1.26.10 it reports none ([#80](https://github.com/cronitorio/cronitor-cli/pull/80)).
- CI now uses `actions/checkout` and `actions/setup-go` v7, and adds a Linux job that builds and unit-tests on the current stable Go alongside the go.mod toolchain ([#79](https://github.com/cronitorio/cronitor-cli/pull/79)).
